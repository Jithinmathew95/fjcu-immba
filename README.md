# FJCU imMBA website

A cleaner, bilingual public site for Fu Jen Catholic University’s **MBA Program in International Management (imMBA)**. Core pages match the official College of Management site: home, about, admissions, dual degree, curriculum, faculty, news, gallery, and contact.

Official reference: [management.fju.edu.tw imMBA](https://www.management.fju.edu.tw/esubweb/immbaengindex/)

## Open the site

This is a static site. No build step is required.

1. Open `index.html` in a browser, or
2. Serve the folder with any local web server if you prefer.

Language: use **EN / 中文** in the top bar. Preference is stored in the browser.

## What was restyled

- Editorial layout, navy and gold, generous spacing
- English as the default international face; Chinese for local admissions
- Search on news and faculty
- Contact form opens mail to `imMBA@mail.fju.edu.tw`

Facts (tuition, dates, partners, faculty) follow the official pages as of September 2026. Confirm live dates and fees with the programme office before publishing.

Gallery panels are placeholders until licensed campus photos are added.
